# Specification

## Summary
**Goal:** Refine UI branding and NFT image presentation by removing the “Studio Art Engine” label, rounding only the main Preview NFT image corners, and shrinking forged token previews on the Forge page.

**Planned changes:**
- Remove the exact text label “Studio Art Engine” anywhere it appears in the UI, including the dashboard header branding and the browser document title.
- Add rounded corners only to the large, central NFT preview image on the Preview page (without changing any other NFT image corner styling across the app).
- On the Forge (Builder) page, reduce the rendered size of the NFT image inside each “FORGED TOKENS” card while keeping the card layout intact (image remains centered and aspect ratio preserved).

**User-visible outcome:** The app no longer shows “Studio Art Engine” in the interface or browser title; the main Preview NFT image has rounded corners; forged token cards display smaller, centered token previews without changing token actions.
